---
title: Enregistrer un versement
---

Menu Activité > [Versements](/versements) > Nouveau versement, ou depuis la [fiche client](/clients).

1. Choisissez le client.
2. Entrez le montant et le mode (espèces, chèque, virement).
3. Pour un chèque, ajoutez le numéro et l'échéance.
4. Enregistrez : la dette baisse aussitôt.
