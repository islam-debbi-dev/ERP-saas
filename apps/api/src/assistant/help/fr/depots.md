---
title: Dépôts et camions
feature: WAREHOUSES
---

Gérez-les dans [Dépôts](/stock/depots). Le stock d'un produit est la somme de ses dépôts. Une vente part du dépôt choisi, sinon du camion du vendeur, sinon du dépôt principal. On n'archive un dépôt que vide ; le dépôt principal reste toujours.

Les camions se gèrent dans [Véhicules](/stock/vehicules) : code de votre entreprise (par exemple VAN-28 MXT 01), type, wilaya et chauffeur du jour. Vos types se créent dans [Types de véhicules](/parametres/types-vehicules). « Changer » remplace le chauffeur ; faites d'abord la clôture si sa journée sur ce camion est ouverte. Une tournée planifiée pour un véhicule suit son chauffeur du jour.
