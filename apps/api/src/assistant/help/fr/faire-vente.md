---
title: Faire une vente
---

Menu Activité > Ventes > Nouvelle vente ([ouvrir](/ventes/nouvelle)).

1. Choisissez le client (ou le client comptoir).
2. Ajoutez les produits, à la recherche ou au code-barres.
3. Entrez ce qui est payé maintenant ; le reste passe en crédit.
4. « Valider », puis imprimez ou partagez.
   Un brouillon ne touche ni le stock ni le compte client.
